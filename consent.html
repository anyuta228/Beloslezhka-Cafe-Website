2. Перечень персональных данных, на обработку которых дается согласие

  • Фамилия, имя, отчество (или имя, указанное при заполнении веб-формы);
  • Контактный номер телефона;
  • Адрес электронной почты (e-mail) — при указании в форме;
  • Параметры и пожелания к бронированию: желаемая дата, время, количество гостей, выбранный зал/стол, примечания;
  • Технические данные, автоматически передаваемые устройством в процессе использования Сайта: файлы cookie, IP-адрес, данные об операционной системе и браузере.

3. Цели обработки персональных данных

  • Регистрация и обработка входящей заявки на бронирование столика или банкетного зала;
  • Осуществление обратной связи с клиентом, подтверждение времени бронирования и состава заказа сотрудниками кафе;
  • Организация питания, обслуживания гостей и доставки блюд;
  • Рассмотрение отзывов, претензий и пожеланий клиентов с целью улучшения качества сервиса.

4. Перечень действий с персональными данными и способы обработки

Настоящее согласие предоставляется на совершение следующих действий (операций) с персональными данными: сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передача (включая передачу по защищенному каналу HTTPS через API ВКонтакте для оперативного уведомления администраторов), блокирование, удаление и уничтожение персональных данных.

Обработка осуществляется с использованием средств автоматизации и без использования таковых. Базы данных с персональными данными граждан РФ расположены исключительно на территории Российской Федерации (дата-центр АО «РСИЦ» / RU-CENTER, г. Москва).
